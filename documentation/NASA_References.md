# NASA References and Data Usage

## Primary NASA sources used in the project

1. **NASA Science — Perseverance and Mars 2020 Spacecraft Components on the Surface (PIA24333).** https://science.nasa.gov/resource/perseverance-and-mars-2020-spacecraft-components-on-the-surface/ — used for the annotated orbital view and identification of landing-system components.
2. **NASA/JPL — Mars 2020 Perseverance Landing Press Kit: Getting to Mars.** https://www.jpl.nasa.gov/news/press_kits/mars_2020/landing/mission/spacecraft/getting_to_mars/ — used for engineering explanations of entry, parachute, heat shield and powered descent.
3. **NASA/JPL Photojournal — PIA24333.** https://www.jpl.nasa.gov/images/pia24333-perseverance-and-mars-2020-spacecraft-components-on-the-surface/ — cross-reference for landing-site image and component locations.
4. **NASA APOD — Perseverance Landing Site from Mars Reconnaissance Orbiter (27 February 2021).** https://science.nasa.gov/image-article/apod-2021-february-27-perseverance-landing-site-from-mars-reconnaissance-orbiter/ — additional description of the orbital view.
