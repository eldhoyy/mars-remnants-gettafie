# MARS REMNANTS – Interactive Mars Hardware Explorer

**Team:** GETTAFIE 2.0  
**Challenge:** NASA Space Apps Challenge 2026 — Abandoned but not Forgotten

An educational interactive experience exploring documented NASA Mars mission hardware left on the Martian surface, including Perseverance entry, descent and landing components.

## Project files

- `website/` — responsive interactive website
- `presentation/` — seven-slide project presentation
- `documentation/` — project description, NASA references and AI disclosure
- `Submission_Text.md` — prepared submission text
- `UPLOAD_CHECKLIST.md` — submission checklist

## Scientific sourcing

Use the NASA references listed in `documentation/NASA_References.md`. The challenge-specific Resources tab must be checked by the team before claiming Global Award data-source compliance. ## Local preview

Open `website/index.html` in a modern browser. No build step is required.

For GitHub Pages, configure the publishing source to the `/website` folder if available. Otherwise copy the contents of `website/` to the repository root and publish from `main` / root.
